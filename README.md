# arnes

A fully client-side AI harness that runs in your browser.

Connect directly to AI providers with your own API keys. No backend, no proxy, no middleman. Conversations and settings stay on your device; requests go directly to your chosen providers.

Made with Web Components. Install it as a PWA or host it yourself.

> [!WARNING]
> Forking this project and hosting it yourself is recommended. [Read why in the wiki](https://github.com/NickStarlight/arnes/wiki/Why-self-hosting).

For more information, see the [wiki](https://github.com/NickStarlight/arnes/wiki).

## Portable HTML

Run `deno task build` to create a self-contained `dist/index.html`. Open it in your browser or host it yourself.
